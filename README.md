# PixVerse 品牌工作台

线上版本已部署至 https://brand-team-production.up.railway.app/ 。本地开发可双击 `启动工作台.command`，保持启动窗口开启，在浏览器使用 http://127.0.0.1:8766/ 。

## 使用

1. 上传 PNG / JPG / WebP 主视觉，自动生成补边色和 Web 色块初始配色；选择 Web、App 资源位及中日英语言。
2. 分别填写所选语言的文案；不自动翻译。App 使用「双行大标题」时，Web 与 App 共用双行标题；切换到「主标题＋副标题」后，Web 两行标题与 App 单行主标题、单行副标题分别编辑并各自保存。
3. 点击「更新设计预览」，在右侧调整某一张的图片缩放、位置和补边渐变。
4. 需要统一构图时，点击画布上方「批量调整」，勾选同一资源位的图片，将当前基准图的缩放与位置同步到所选图片。可选「同时同步左侧渐变」；退出后仍可单独调整某一张。Web 与 App 不可交叉选择。
5. Web 与 App 需要不同图片时，在右侧「资源位图片」替换当前资源位图片。独立图片同步该资源位的中、英、日三张卡片，不跨资源位；仍可逐张微调构图。上传后该资源位缩放与位置恢复为 100% / 0 / 0，保留渐变宽度；「恢复使用母版图」可一键回退。
6. 在左侧「Web 模板色块」使用「自动匹配主视觉」或「自定义」；自动匹配后可修改两层色块的渐变色和不透明度。该设置同步到所有 Web 语言，不影响 App。形状来自现有 Figma 原始矢量路径。
7. 点击顶部「选择下载」进入下载选择，默认全选当前结果；可跨 Web、App 和语言任意勾选。选择一张时下载 PNG，选择多张时下载 ZIP。下载选择只决定导出范围，不同步构图或其他参数；「批量调整」仍只允许同一资源位。
8. 工程自动保存到当前浏览器；顶部会显示「已保存到本机」。在「我的工程」中可使用飞书登录，将当前工程保存到云端；首次保存后，后续本地修改会延迟自动同步。也可使用「备份工程」下载 JSON 工程文件，并通过「打开工程」继续编辑。工程文件不是最终交付图片。

「活动文字颜色」默认纯白 `#FFFFFF`，支持自定义取色或输入 6 位 HEX 色值，同步当前工程全部语言、资源位的主副标题，随草稿和工程保存，支持撤销／重做。仅保留「纯白」和「自定义颜色」；旧工程的模板原色设置迁移为默认白色。实际导出、刷新回读及颜色校验见 [验证记录](验证/2026-09-24_自定义文字颜色/验证记录.json)。

## 界面图标规范

- 界面功能图标统一维护在 `dist/index.html` 的 SVG symbol 集合中，通过 `<use href="#i-*">` 引用；不使用 Unicode 箭头、叉号、加减号或页面内临时绘制的 SVG 代替。
- 所有图标采用 `24 × 24` viewBox、无填充描边、`currentColor`、圆角端点与圆角连接；全站线宽由 `--icon-stroke: 1.75` 统一控制。包含矩形边框时统一使用 `rx="2"`，不混用尖角框和不同半径的圆角框。
- 视觉尺寸固定为三档：侧栏导航 `22 px`、常规操作 `18 px`、紧凑工具和下载操作 `16 px`。同一行、同一层级的图标必须使用同一尺寸档位。
- Logo、品牌 Icon、素材预览和状态插画属于内容资产，不套用界面功能图标规则。
- 新增图标时先加入共享 symbol，再引用现有尺寸档位，并运行 `验证/icon-system.test.cjs`，避免局部图标的线宽、大小或绘制方式偏离全站规范。

自动配色在本机分析原图左侧的主要颜色，生成补边色和两层同色系 Web 渐变；会过滤少量亮点，并参考当前文字的明暗。仅作为初值，不承诺识别所有主体或保证复杂背景的衔接。首次示例、替换主视觉时计算；刷新、打开当前工程不会重新覆盖已保存配色。两处各有重新匹配按钮，手动调整会保留。Web 色块仅保留「自动匹配主视觉」和「自定义」；旧工程中的「礼盒紫色」「规范原配色」会按工程主视觉重新自动匹配。自动匹配不打开补色开关，不改变色块形状、透明度、字体及构图。全透明图保留已有颜色并提示手动选色。

## 尺寸与保真

工作台布局：桌面端左侧设置、中间预览、右侧单张调整独立滚动，顶部工具栏与左侧底部「更新设计预览」保持可见。主视觉、语言文案默认展开；资源位与版式、Logo、色块默认收起并显示配置摘要。701–1100 px 窄窗口通过「单张调整」展开侧面板；700 px 及以下使用纵向页面。画布底部提供 10%–400% 观看缩放、适应窗口（按宽度）、查看全部（全部画板适应可视区域）和放大选中（选中画板居中）。画板按资源位分行、按已生成的语言分列（中文、English、日本語）；选一种语言一列、两种两列、三种三列，窄窗口保留排列。勾选变化在点击「更新设计预览」后应用。每张卡片也有「放大查看」。100% 对应模板规范的 1× 显示尺寸，PNG 始终按 4× 输出。超过窗口时可横向、纵向滚动；画布区域内 Ctrl/⌘＋滚轮可缩放，聚焦浏览区域后可用 +/−、0（适应窗口）。支持拖动空白处平移、空格临时平移、手型模式在图片上平移；输入文案时空格正常输入。查看全部可找回画板。观看状态不写入工程或撤销历史，刷新恢复适应窗口。预览按缩放和屏幕像素密度从原素材重绘（4×–8×），DOM 使用布局缩放；导出仍单独按规定 4× 绘制。右侧「主视觉缩放」仍用于修改构图。

- Web 使用 330 × 139.5 的 1× 坐标；PNG 输出 1320 × 558。
- App 使用 381 × 120 的 1× 坐标；PNG 输出 1524 × 480。
- 2026-09-28 Web 全局规范版本升级为 `2026-09-28-v2`：标题区固定为 `[12, 34, 139.5, 67.5]`，右边界从标题区计算为 `151.5`；英文实际锚点为 `x=12.5`，中日文为 `x=13`。这些是 Figma 最终校准坐标，Web 绘制不再二次移动字形；安全区仍按可见像素检查。App 坐标与动态光学对齐保持不变。
- Web 左侧品牌色图形与基础渐变整体右移 2 px（导出为 8 px）；Logo 锁定距上 10 px、距右 12 px、高 14 px。旧的 8 px 标注、横线和端点刻度不在网页辅助线中绘制。
- `2026-09-23-v1` 本地草稿和工程可定向迁移到新版；迁移保留文案、图片、资源位独立图、裁切、调色、Logo 和单张参数，Web 坐标统一读取新全局规范。
- 文字、色块均以矢量方式在导出画布绘制；图片直接从原图等比采样，不经过预览截图，不调用 AI 重绘。
- 2026-09-23 已按 9 种 Figma 原生 PNG 修正字体整行排版、基线、颜色、渐变和官方 Logo 留白；**尚未达到逐像素零差异**。详情与原图见 [全量核验](验证/2026-09-23_模板全量核验/核验结果.md)。
- 「左侧补色」开关默认关闭，同步全部设计；开启后应用补边色、边缘衔接和自定义左侧渐变。关闭时保留颜色与单张渐变参数，不改变图片缩放、位置；原图未覆盖处保持透明。开关随草稿／工程保存，支持撤销、重做。
- 单张文字衬底仅保留「自定义左侧渐变」（开启左侧补色后可调），范围 0–80%，0% 关闭此渐变。旧工程统一转为自定义，保留已有渐变宽度、图片缩放和位置；「恢复自动适配」只重置缩放与位置，保留渐变宽度。
- 批量构图仅在相同资源位内生效：Web 只能同步至 Web，App 只能同步至 App。同步后每张仍保留独立参数，退出批量模式即可单独修改。批量同步记为一步撤销；批量选择本身不写入工程，同步后的单张参数会正常保存。
- 资源位独立图片以 Web 或 App 为作用范围，同一资源位的中、英、日共用一张图；不提供语言卡片级图片，也不提供无差别批量上传。替换图片时自动取补边色作为初值，右侧色板可手动微调；Web 独立图片同时为 Web 渐变色块提供自动配色初值。资源位图片、补边色和构图均随草稿及工程文件保存，并支持一步撤销／重做。
- 自动适配使用主体靠右、左侧放文字的规则，不包含主体识别。导出前仍需人工检查构图、清晰度和对比度。
- Web 色块形状数据来源：Figma 文件 gUue0wj3zWk07IU4lLdlrI，画板 534:935，矢量 534:948 / 534:949，2026-09-28 回读；颜色由自动匹配或自定义设置决定。
- Web 标题每行位置已按 2026-09-28 Figma 最终节点配置；浏览器与 Figma 的字体光栅化仍可能有不超过数个输出像素的抗锯齿差异。
- 文案同步按版式结构决定：App「双行大标题」与 Web 共用标题；App「主标题＋副标题」使用独立主副标题，修改 Web 不影响 App，切回双行版式会恢复共用标题。旧工程首次打开时，中文、日文通过去除换行、英文通过换行改空格生成 App 单行标题初值；初值过长时只提示缩短，不改变模板字号。异常多行数据只绘制允许的第一行并阻止导出，不会覆盖副标题。Web 双行标题、App 双行标题和 App 主副标题均按每一行当前字形的实际左边界进行视觉对齐，各自保留模板锚点，不使用语言固定偏移；开头标点和显式空格保留原排版。

## 云端工程与权限

品牌素材、本地编辑和图片下载保持公开，不要求登录。飞书只负责确认用户身份；登录用户只能读取、保存和删除自己的云端工程。云端工程使用版本号阻止多个页面互相覆盖。`FEISHU_BOOTSTRAP_ADMIN_NAME=赵瑞秀` 只在首次匹配登录时使用，成功后管理员权限绑定到该飞书账号的 `open_id`，同名账号不会继承权限。管理员概览只展示用户数、工程数和存储量，不读取其他成员的工程内容。

服务端需要 Node.js、PostgreSQL 和以下环境变量：`PUBLIC_URL`、`DATABASE_URL`、`SESSION_SECRET`、`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_BOOTSTRAP_ADMIN_NAME`。参考 `.env.example`。在飞书开放平台中，需要创建企业自建应用，将 `${PUBLIC_URL}/api/auth/feishu/callback` 加入重定向 URL，并发布到允许使用的成员范围。

当前浏览器仍只自动保存一份本地工程；清理浏览器数据会删除本地草稿。图片仍在浏览器生成和导出，云端保存的是现有工程 JSON，不改变工程文件格式或导入导出逻辑。公共模板更新须更新 `dist` 中的配置和资产并重新部署；不会自动覆盖已保存工程的活动颜色。暂不提供多人实时共同编辑、模板在线发布、AI 扩图或 PixVerse 调用。

图片上传限制为 40 MB、5000 万像素；浏览器可用内存会影响处理速度。
