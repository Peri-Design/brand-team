物料工作台使用帮助

  • 未填写的标题默认留空；新增 Web / App 会沿用已填写的同语言共享标题。模板示例仅用于挑选版式，不自动填入。
  • Web / App 支持中文、English、日本語，以及同语言双行标题同步。国内社媒仍使用已提供的中文规范；没有擅自增加海外模板。
  • 复用现有 Web / App 字体、模板参数和检查逻辑；提供独立补边色、自动取色、Web 色块及 Logo、文字颜色。
  • 保留选中图片拖动与拉角缩放；支持独立画布缩放、手型、撤销重做及同资源位批量同步构图。
  • 云端保存图片、文案和物料设置；单图导出 PNG，多图导出 ZIP。

保存范围：设计自动保存到当前账号的云端文件，本机保留未同步修改的恢复副本。保存失败时请点击“重试同步”。

画布 100% 对应规范 1× 尺寸，导出固定为 4×。拖动空白平移，+ / − 缩放，0 适合窗口。“聚焦编辑”居中显示当前物料并打开右侧设置，返回后恢复原浏览位置；“缩放至选中”在总览中居中放大当前物料。
